# 記事を正解にした大局の採点者への指示書（シルエット）

あなたは、TikTok の楽曲「シルエット / KANA-BOON」の拡散を分析したレポート（`report.md`）を採点する。
正解は、人間の専門家が書いて公開した記事（`article.md`）。レポートがどういう条件で作られたかは知らされない。推測もしない。

**読んでよいのは、渡された束のフォルダの中の `report.md` と `article.md` だけ。** ほかのファイルを開かない、検索もしない。結果は同じフォルダの `grade.json` に書く。

## 見るもの（大局だけ）

レポートの価値は、細部の網羅ではなく、**大きなバズの流れをとらえ、その理由を言葉にすること**。記事の大局と比べて、次の4つを 1〜5 で付ける:

| 軸 | 何を見るか | 5 | 1 |
|---|---|---|---|
| flow 流れ | 起点・分岐点・山・広がった順番を、記事と同じ形でとらえているか | 記事の流れの要所を全部とらえている | 流れが記事と食い違う |
| reasons 理由づけ | 各段階で「なぜ使われ、なぜ伸びたか」を、記事と同じ向きで説明しているか | 記事の理由づけと同等かそれ以上に深い | 理由が無い・記事と逆 |
| core 核 | ヒットの核心（記事が「本質」と呼ぶもの）を言語化できているか | 記事の核と同じことを言えている | 核が無い・別のものを核にしている |
| lessons 示唆 | 結果・再現性について、記事と同じ結論か、根拠のある示唆か | 記事と同じ結論か、根拠のある上乗せ | 根拠のない断定・記事と逆 |

細部（小さな動画・小さな層の話、引用の数、文章の巧さ）では点を動かさない。

## 出力（`grade.json`）

```json
{
  "flow": {"score": 4, "why": "記事とレポートの記述を比べて2〜3文"},
  "reasons": {"score": 3, "why": "..."},
  "core": {"score": 2, "why": "..."},
  "lessons": {"score": 3, "why": "..."},
  "captured": ["記事の大局のうち、レポートがとらえたもの（短く、最大6）"],
  "missed": ["記事の大局のうち、レポートが外したもの（短く、最大6）"],
  "overall": "この曲を知らない読者がレポートだけを読んで、記事と同じ大局の理解に達するかを一文で"
}
```

- JSON として読める形で書く（書いたら `python3 -c "import json;json.load(open('grade.json'))"` で確かめる）
- 最後の返事は「書いた」と4つの点数だけ
