# 対の比較の採点者への指示書（コメントに基づく発見だけを比べる）

あなたは、同じ TikTok の楽曲の拡散を分析したレポート2本（`A.md`・`B.md`）を比べる。どちらがどういう条件で作られたかは知らされない。推測もしない。

**読んでよいのは、渡された束のフォルダの中の `A.md` と `B.md` だけ。** ほかのファイルを開かない、検索もしない。結果は同じフォルダの `judge.json` に書く。

## 何を比べるか

**コメント（視聴者の声）に基づく中身だけ**を比べる:
- 視聴者がどう反応したか（反応の型・言葉・言語や地域による違い・少数だが目立つ反応）
- コメントから読める、投稿者がこの曲を使った理由や文脈
- 引用されたコメントが主張をどれだけ具体的に支えているか

拡散の経路・段階の区切り・日付・再生数・界隈の分け方など、コメントに基づかない中身の違いは**比べない**（文の書き方・長さ・体裁も比べない）。

## やること

1. 両方を最後まで全部読む
2. **A にだけある、コメントに基づく発見**と、**B にだけある、コメントに基づく発見**を書き出す（それぞれ最大8つ）。
   - 「発見」は、読者が「なるほど」と思う中身の単位（例: 「スペイン語圏で歌い出しが空耳として回った」）。同じ発見を別のコメントで支えているだけなら「片方にだけある」に入れない
   - 各発見に、そのレポートの該当の一文をそのまま引く（`quote`）。重さを `大`（レポートの結論や章の主張に効く・読者が知らないと困る）か `小`（細部・彩り）で付ける
3. 総合して、**視聴者の反応を、より豊かに正確に伝えているのはどちらか**を5段階で判定する: `A がはっきり良い`／`A がやや良い`／`同じくらい`／`B がやや良い`／`B がはっきり良い`
4. 理由を2〜3文で
5. 片方だけを読んだ読者が見落とす大事なことがあれば一文ずつ（無ければ「なし」）

## 出力（`judge.json`）

```json
{
  "only_A": [{"finding": "...", "quote": "A.md の一文", "weight": "大"}],
  "only_B": [{"finding": "...", "quote": "B.md の一文", "weight": "小"}],
  "verdict": "同じくらい",
  "why": "...",
  "miss_if_only_A": "なし",
  "miss_if_only_B": "..."
}
```

- JSON として読める形で書く（書いたら `python3 -c "import json;json.load(open('judge.json'))"` で確かめる）
- 最後の返事は「書いた」と verdict と、only_A・only_B の `大` の数だけ。中身を返事に書き写さない
