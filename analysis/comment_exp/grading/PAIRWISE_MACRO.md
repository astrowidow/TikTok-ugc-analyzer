# 対の比較（大局）の採点者への指示書

あなたは、同じ TikTok の楽曲の拡散を分析したレポート2本（`A.md`・`B.md`）を比べる。どちらがどういう条件で作られたかは知らされない。推測もしない。

**読んでよいのは、渡された束のフォルダの中の `A.md` と `B.md` だけ。** ほかのファイルを開かない、検索もしない。結果は同じフォルダの `judge.json` に書く。

## このレポートの価値（比べる軸）

このレポートの価値は、細部を網羅することではなく、**大きなバズの流れをとらえ、その理由を言葉にすること**にある。だから次の4つだけを比べる:

1. **流れの捉え方**: 起点・分岐点・山（大きく伸びた所）・広がった順番を、正しくとらえているか
2. **理由づけ**: 各段階で「なぜこの人たちが使ったのか・なぜ伸びたのか」を、筋の通った言葉で説明しているか。根拠（大きな動画・視聴者の反応）で支えているか
3. **ヒットの核**: この曲がヒットした核心を、一言で言える形に言語化できているか
4. **再現性・示唆**: ほかの曲や作り手に役立つ示唆を、根拠の範囲で引き出しているか

**比べないもの**: 小さな層・小さな動画にしか無い細部の発見、引用の数、文の書き方・長さ・体裁。
片方にしか無い細部があっても、上の4つ（大局）に効かないなら差としない。

## やること

1. 両方を最後まで全部読む
2. 上の4つそれぞれについて、`A がはっきり良い`／`A がやや良い`／`同じくらい`／`B がやや良い`／`B がはっきり良い` を付け、理由を1〜2文で
3. **大局の主張の違い**を書き出す: A にだけある大局の主張・B にだけある大局の主張（それぞれ最大5つ）。各主張にレポートの該当の一文を引く（`quote`）。
   「大局の主張」は、流れ・理由・核・示唆のどれかに当たる主張だけ（細部の発見は入れない）
4. 総合して、**大きなバズの流れと理由を、より正しく・深く言語化しているのはどちらか**を5段階で判定し、理由を2〜3文で

## 出力（`judge.json`）

```json
{
  "axes": {
    "flow": {"verdict": "同じくらい", "why": "..."},
    "reasons": {"verdict": "...", "why": "..."},
    "core": {"verdict": "...", "why": "..."},
    "lessons": {"verdict": "...", "why": "..."}
  },
  "only_A": [{"claim": "...", "quote": "A.md の一文"}],
  "only_B": [{"claim": "...", "quote": "B.md の一文"}],
  "verdict": "同じくらい",
  "why": "..."
}
```

- JSON として読める形で書く（書いたら `python3 -c "import json;json.load(open('judge.json'))"` で確かめる）
- 最後の返事は「書いた」と verdict と、only_A・only_B の数だけ。中身を返事に書き写さない
