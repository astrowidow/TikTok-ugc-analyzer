## 2. 前提になる事実

- **TikTok のアカウントが要るのはコメント取得だけ。** 一覧と属性はログインなし（ヘッドレス）で取っている（`acquire/pipeline.py`、`analysis/enrich.py`）。ただし、どちらも取る側の回線から TikTok に届く
- コメント取得は**実画面の Chrome**（描画が止まると無言で20件頭打ち。2-9。隠れたウィンドウは「フォーカスの模擬」で回る）、1曲およそ13時間（要求の速さで決まる。並列にしても1つの回線・1つのアカウントでは速くならない）
- **Claude のプラグインは、PC で動くプログラム（ローカルの MCP）を含められる**。ただし **2026-10-06 から Pro・Max の新しい Cowork はクラウドで動き**、プラグインに入れたローカルの MCP は**クラウドの Cowork では起動されず警告も出ない**と報告されている（公式リポジトリの不具合報告、「対応予定なし」で閉じられた。公式の説明どうしも食い違う）。Cowork でローカルの MCP を使うには Node.js が別に要る、という報告もある
- Claude のデスクトップ拡張（.mcpb）は Node を同梱、Python は同梱しない（uv 型なら初回に自動で用意）
- TikTok 公式の研究用 API（コメント取得あり）は、米欧などの**学術機関・非営利の研究者だけ**。企業・個人は使えない → 対象外
- 外部の取得サービス（Apify の TikTok コメント取得など）は 1,000件あたり 0.3〜1 ドル程度（シルエット規模の約8千件で数ドル）。中身は業者の仕組み（住宅プロキシや署名の再実装を使っていることが多い）

## 4. 案2（取得ランナー）の中身

「友達の PC に取得サーバーを入れる」の形。GitHub の自前ランナー（自分の機械で CI の仕事を受けて走らせる）と同じ考え方。

```
友達の AI（Cowork・クラウド）──接続──> サービス（型・データ。今の Windows 機、将来はどこでも）
                                            ^  仕事を受け取る／結果を上げる
                                            |
                              友達の PC の「取得アプリ」（Chrome を開いて、友達の捨て垢で取得）
```

- 友達が AI に「〇〇を分析して」→ サービスがその人の仕事として受け付ける → **その人の PC の取得アプリ**が仕事を受け取り（アプリがサービスに1分おきに聞く。AI は見に来ない）、一覧 → 属性 → プール → コメントを取り、結果をサービスに上げる → 友達が「続けて」→ **AI の側は今と同じ**（T1 で動いた形、ChatGPT にも後から足せる）
- **TikTok へのアクセスは全部、友達の PC と回線から。** 運営の機械は TikTok に触らなくなる（運営の取得は、運営の PC の取得アプリとして同じ形で）。
  副産物: サービス（型とデータ）は住宅の回線が要らなくなるので、将来は家の外（安いサーバー）に移せる
- **ログインは友達が自分で**: 取得アプリが専用の Chrome のウィンドウ（専用のプロファイル）で TikTok のログイン画面を開き、友達が捨て垢で入る。認証コードは友達のメールに届く。運営は関わらない
- 順番待ちは消える（各自の PC で並行）
- 取得アプリは止まったこと・PC が閉じていることをサービスに知らせる（`status` で「あなたの PC の取得が止まっています」と出る）。直した版はサービスから自動で入れ替える

**友達の手間（最初の1回）**: ①Claude アプリを入れてログイン ②接続を足す ③**捨て垢を作る**（別のメールアドレスが要る）④**取得アプリを入れる**（運営が LINE で送る、その人用に設定済みのリンク）⑤**取得アプリの画面で捨て垢にログイン**。
**分析のたび**: 「〇〇を分析して」と言い、**取得が終わるまで PC を開いたまま・電源につないでおく**（13時間前後。ノート PC はふたを閉じると止まる。スリープはアプリが止める）。

**入れ方の候補**

| 入れ方 | 良いところ | 弱いところ |
|---|---|---|
| a デスクトップアプリ（今の Python をそのまま固めて Mac・Windows 用に） | 今の取得の部品（`acquire/`）をほぼそのまま使える。Claude・ChatGPT に依らない | 署名なしだと Mac・Windows が「開発元が未確認」と警告する（Mac は Apple の開発者登録 年99ドルで消せる）。Chrome は友達の PC のものを使う |
| b Chrome 拡張 | 入れるのがボタン1つ（ストア経由）。Python が要らない | 取得の部品を JavaScript で書き直し。本垢と混ざらないよう Chrome のユーザーを分ける手間。ストアの審査（スクレイピング）。描画の模擬に「デバッグ中」の表示が出る |
| c Claude のデスクトップ拡張（.mcpb） | ダブルクリックで入る。Node 同梱 | Claude デスクトップが開いている間しか動かない。JavaScript で書き直し。Claude 専用 |
| d Claude のプラグインに入れる | ユーザーの最初の案 | **クラウドの Cowork で起動されない**（第2章）。今は採れない |

**弱いところ（案2 全体）**

- 友達の手間が3つ増え、取得中は PC を開いておく制約が毎回つく（C4 から外れる）
- **友達の本垢と同じ家の回線を使う。** 本垢をスマホで家の Wi-Fi から使っていれば、捨て垢と同じ IP になる（結び付けられるかは未確認。運営は今すでに同じ状態）。マーケターの本垢が大事なら、友達に事前に伝える必要がある
- 友達の PC で止まっても、運営からは見えにくい（取得アプリの知らせで補う）
- 結果をサービスに上げる量: 1曲で数十 MB（サムネの一覧画像はアプリ側で作って上げる）。ngrok の無料枠は月 1GB なので、圧縮するか Cloudflare Tunnel に替える
