## 1. 何を確かめる試作か

利用者（友達）の Mac の側の使い心地だけ。**サービスにはつながない**（仕事はメニューから自分で頼む）。

| 確かめること | どこで分かるか |
|---|---|
| 入れられるか（署名なしのアプリを開く手順） | 第3章 |
| 最初の起動・捨て垢のログインが自分でできるか | 第4章 |
| 取得中に邪魔にならないか（Chrome は Dock にしまわれたまま・ファン・電池） | 第5章 |
| 画面が消えても・ふたを閉じても、続きから取れるか | 第5章 |

## 3. 入れる（友達がやるのと同じ手順）

ファイル: `/Users/belle/workspace/TikTok-ugc-analyzer-collector/collector/dist/UGC-Collector-0.1.0-download.dmg`
（「ネットからダウンロードした」印を付けた写し。友達が LINE などから落としたときと同じく、Mac の安全機能に止められる。
印なしの `UGC-Collector-0.1.0.dmg` だと止められないので、体験を見るなら `-download` のほう）

1. .dmg をダブルクリック → 開いた窓で「UGC Collector」を「アプリケーション」へドラッグ
2. アプリケーションフォルダの「UGC Collector」をダブルクリック → **「開いていません」「Apple は…検証できませんでした」と出る → 「完了」**
3. **システム設定 → プライバシーとセキュリティ** → 下のほうの「“UGC Collector”は…ブロックされました」の **「このまま開く」** → パスワード（または Touch ID）
4. もう一度出る確認で **「開く」**

署名なし（Apple の開発者登録をしない。2026-10-01 の判断）なので、2〜4 は最初の1回だけ要る。友達には運営が LINE 通話で案内する想定。

## 4. 最初の起動

1. メニューバーに**割れた音符のアイコン**が出る（Dock には出ない。Rectangle と同じ）
2. 通知は「スクリプトエディタ」名義で出る（署名なしのアプリは、Mac が通知の一覧に載せてくれない。2026-10-02 の試しで分かった）。出ないときは「システム設定 → 通知 → スクリプトエディタ」を許可にする
3. **取得用の Chrome**（ふだんの Chrome とは別のプロファイル）が開いて TikTok のログイン画面になる → **捨て垢でログイン**（認証コードは捨て垢のメールに届く）
4. ログインできると、通知「準備OK」が出て、Chrome は Dock にしまわれ、しばらくすると閉じる
5. 「ログイン時に起動」は最初から入っている（メニューで外せる。Mac が「バックグラウンド項目が追加されました」と知らせることがある）

メニューの中身:

| 項目 | 中身 |
|---|---|
| （1行目） | 今の状態（準備OK・待機中／取得中: 曲名 — コメントを取る 35/197本・残り約8時間／ログイン待ち／止まっています） |
| 曲を取得する（本番の規模・約13時間）… | **試作だけ。** 本線では、ここは AI との会話（「〇〇を分析して」）になる |
| ちょいとり（試し・約5分）… | 一覧を先頭20本、コメントは2本・各30件、返信は開かない（要求の速さは本番と同じ） |
| 止まった取得を続きから再開 | 自動の取り直し（3回まで）を使い切ったものを、済んだところの続きから |
| 取得の画面を見る／しまう | しまってある取得用の Chrome を前に出す／Dock に戻す |
| TikTok にログイン | ログインが切れたとき |
| データのフォルダを開く／取得の記録を開く | `~/Library/Application Support/UGC Collector/analyses/`／いちばん新しい分析の `fetch_log/pipeline.log` |
| 取得中は画面を消さない | 既定はオフ（Mac をスリープさせないだけで、画面は消える）。画面が消えて描画が止まるようならオンにする |
| ログイン時に起動 | Mac を起動したら自動で立ち上がる |
| 終了 | 取得の途中なら確認してから止める。次に開くと続きから |

## 5. 試しの取得

1. メニュー →「ちょいとり（試し・約5分）…」→「曲名 / アーティスト名」か楽曲ページの URL → 「取得を始める」
2. 一覧と属性の間は画面に何も出ない（ヘッドレスで取る）。**コメントの段に入ったときに初めて**取得用の Chrome が最小化で開き、Dock に入る。あとは**ふつうに Mac を使ってよい**。取得中に Chrome を閉じても、アプリが数秒で最小化で開き直す
3. 終わると通知「〇〇の取得が終わりました（コメント N本・M件）」

見てほしいこと（感触）:

- 取得中、何か気になったか（Dock の Chrome のアイコン・ファン・電池・重さ）
- 画面が消えたあとも取れていたか → 「取得の記録を開く」で、`描画: visible フレーム=… OK` の行（アプリの記録 `~/Library/Application Support/UGC Collector/logs/collector.log` に10分ごと）。
  止まっていれば通知「取得の画面の描画が止まっています」が出る
- （試すなら）途中でふたを閉じて、数分後に開く → 続きから取り直すか（アプリはスリープの直前に取得を止め、起きたら30秒後に続きから）
- 取れたデータ: `pipeline.log` の最後の comments の行に `"mixed_comments": 0`（混入）・`"stuck_at_20": 0`（20件頭打ち）

## 6. 本線への合流（感触が良かった場合）

試作で作ったもの（`collector/`）はそのまま使い、次を足す。**本番に入れるのは段3の OK の後**（`docs/STAGE4_HANDOVER.md` 第3章）。

| 足すもの | 中身 | 場所 |
|---|---|---|
| 仕事の受け取り先（サービス） | `jobs.LocalJobs` の代わりに、サービスから「この人の仕事」を受け取る。待つ間は長くつないだままの要求1本（ngrok の無料枠は月2万リクエストなので、数分おきに聞きに行かない） | `collector_app/jobs.py` に `ServerJobs` |
| つなぎ方 | アプリが6桁の番号を出し、利用者が Claude に「取得アプリをつないで 482913」と言う → 接続口の道具がその人とアプリを結ぶ（URL を貼らない） | 接続口に道具1つ、アプリに表示 |
| 結果を上げる | 取得が終わったら raw/（サムネを除く）・fetch_log/・derived/ を1つに固めて上げる | サービスに `/runner/…`（新しいモジュール） |
| 受け付けの振り分け | `start_analysis` を、アプリをつないだ利用者ならその人の Mac へ。取得中・Mac が止まっている（閉じている）を `status` と `next_task` の文面に | `proto_runner.py`・`mcp_proto.py` |
| 通知の文面 | 「Claude で『〇〇の分析を続けて』と言ってください」 | `collector_app/app.py` |
| 部品の入れ替え | 取得の部品だけをサービスから入れ替える（運営の鍵で署名したものだけ受け付ける）。アプリ本体は入れっぱなし | `collector_app/config.py` の code の置き場をそのまま使う |

見積もり: 1〜1.5日（サービス側の受け渡し・つなぎ方・上げる口・振り分け、アプリの受け取り先、本番での一周）。

## 7. 消し方

メニュー「終了」→ アプリケーションフォルダの「UGC Collector」をゴミ箱へ →
`~/Library/Application Support/UGC Collector/`（取ったデータと取得用 Chrome のプロファイル）と `~/Library/LaunchAgents/jp.ugc-analyzer.collector.plist` を消す。

## 8. 作り方（運営）

```
cd /Users/belle/workspace/TikTok-ugc-analyzer/collector
./build.sh            # dist/UGC Collector.app と dist/UGC-Collector-<版>.dmg（自己点検つき）
```

- Python 3.13（python.org 版）＋ PyInstaller。取得の部品は .py のまま同梱し、起動時に `~/Library/Application Support/UGC Collector/code/<版>/` に写して使う
  （アプリの中は書き込めないことがあるため。部品が横にログを書く）。アプリの実行ファイルは部品から見て「python」の代わりもする（`-m acquire.worker`・`analysis/*.py`）
- アイコンは `collector/assets/icon.svg`・`menubar.svg` から `make_icons.sh` で作る（TikTok のロゴではなく、オリジナルの八分音符を割った絵柄）
- TikTok に触らない試験: `UGC_COLLECTOR_TEST_NO_CHROME=1`（Chrome とログインを飛ばす）、`--selftest`（同梱物）
