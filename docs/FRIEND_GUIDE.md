# UGC Analyzer の使い方（1枚）

> 友達に見せるのはページ版「UGC Analyzer の始め方」（https://claude.ai/artifact/Tp343YwoMtSrFWKuJcCLmC 、元は `docs/pages/guide.html`）。この紙はその元になった1枚もの。数字や手順を変えたら両方を直す（`docs/pages/README.md`）

TikTok で曲がどう広まったかを、あなたが使っている Claude か ChatGPT が分析してレポートにします。
あなたがすることは、**AI に決まった一言を言うこと**だけです。

---

## 最初の1回（20分ほど。上から順に進めれば、ひとりでできる）

**用意するもの**: Mac（2020年以降の M1・M2・M3・M4）／Google Chrome／Claude の有料プラン（Pro 以上）か、ChatGPT（Mac のアプリ・macOS 14 以降。無料プランでも動くが、レポートの質がかなり落ちるので有料プランをおすすめ）／
**TikTok の分析専用のサブアカウント**（分析のためだけに使う、ふだんとは別のアカウント。ふだんのアカウントは使わない。持っていなければ手順4で作るので、ふだん使っていないメールアドレスを1つ用意する）

1. **Claude（または ChatGPT）を Mac に入れる**: Claude の人は https://claude.ai/download 、ChatGPT の人は https://openai.com/chatgpt/download/ から入れて、ログインする
2. **UGC Analyzer を入れる**: https://github.com/astrowidow/TikTok-ugc-analyzer/releases/latest/download/UGC-Analyzer.dmg を開くと、`UGC-Analyzer.dmg` というファイル（60MB ほど）がダウンロードされる（新しい版が出たときも、同じリンクで新しい版が落ちてくる）。「ダウンロード」フォルダのそのファイルをダブルクリック。小さな窓に「UGC Analyzer」と「アプリケーション」の2つが並ぶので、「UGC Analyzer」を「アプリケーション」の上までドラッグして離す
3. **UGC Analyzer を開く**（最初の1回だけ、ひと手間あります）
   1. Finder の「アプリケーション」フォルダで、「UGC Analyzer」をダブルクリック
   2. 「“UGC Analyzer”は開いていません」という警告が出る。運営が Apple に登録していないアプリなので出る警告で、壊れているわけではない。警告の中の「**完了**」を押して、いったん閉じる（「ゴミ箱に入れる」は押さない）
   3. 画面左上のりんごマーク →「**システム設定**」→ 左の列の「**プライバシーとセキュリティ**」
   4. 右側をいちばん下までスクロールすると、「“UGC Analyzer”は〜ブロックされました」という文がある。その横の「**このまま開く**」を押す
   5. Mac のパスワード（または指紋）を入れる。もう一度確認が出たら「**開く**」

   このひと手間は最初の1回だけ。次からは、ダブルクリックだけで開く
4. **TikTok にサブアカウントでログイン**: UGC Analyzer が開くと、Chrome が自動で立ち上がって TikTok のログイン画面が出る。そこで分析専用のサブアカウントでログインする。ふだんのアカウントではログインしない
   - サブアカウントを持っていない人は、同じ画面で「登録」を選び、ふだん使っていないメールアドレスでアカウントを作ってからログインする（確認のコードは、そのメールアドレスに届く）
   - **サブアカウントは、スマホの TikTok アプリで作ったりログインしたりしない**（ふだんのアカウントと同じスマホに入れないため）
5. **「つなぎました」が出たら「開き直す」を押す**: ログインが済むと、UGC Analyzer が自動で Claude（ChatGPT）につなぎ、「**Claude につなぎました**」（ChatGPT の人は「**ChatGPT につなぎました**」）という小さな窓が出る。「**開き直す**」を押すと、Claude（ChatGPT）が一度閉じて自動で開き直し、UGC Analyzer が使えるようになる（話していた会話は消えない）
   - 出てこないときは、画面右上の **割れた音符のアイコン** →「Claude につなぐ」（ChatGPT の人は「ChatGPT につなぐ」）→「開き直す」

これで準備は終わりです。割れた音符のアイコンは、いつも画面右上にいます（Mac を起動すると自動で立ち上がります）。

**ChatGPT の人へ**: 話しかけるのは ChatGPT のアプリの **Work** です（ふだんの Chat や、ブラウザの chatgpt.com では UGC Analyzer につながりません）。

## 分析するとき（決まった一言）

| いつ | AI に言うこと | そのあと |
|---|---|---|
| はじめるとき | **「UGC Analyzer で〇〇（曲名）／△△（アーティスト名）を分析して」** | 「UGC Analyzer で」を付けないと、AI はふだんどおりに答えます（分析は始まりません）。付けると、Mac が TikTok でその曲の楽曲ページを探し（数十秒）、AI が「このページで集めます」と見せてそのまま始めます（同じ曲の sped up 版などがあれば、合わせて集めます）。そこから **2〜3時間**（曲の大きさしだい）、Mac が TikTok から集めます。ページが違っていたら「〇〇の取得をやめて、このページでやり直して」と URL を渡せば直せます |
| 終わったら | **「〇〇の分析を続けて」** | 5分ほどで「界隈（どんな人たちが使ったか）の案」が出るので、「OK」か、直したいところを言う。そこから **40分〜1時間** で完成（曲の情報や TikTok の外の数字をウェブで調べる時間を含む） |
| 完成したら | （何も言わなくてよい） | AI がレポートのリンクを出します。割れた音符 →「**レポートのフォルダを開く**」でも見られます |

**Claude の人は、送る前にウェブ検索をオンに**: 入力欄の左下の「＋」→「ウェブ検索」にチェックが付いているか見る（付いていなければ押す）。AI が曲の情報や YouTube・チャートの数字を調べてレポートに入れるためです。会話ごとの切り替えなので、「続けて」を別の会話で送るときも確かめる。「＋」の中に「ウェブ検索」が無ければ、そのままで大丈夫。ChatGPT の人と Code タブで頼む人は何もしなくてよい

**集めている間・書いている間のお願い**

- **Mac を開いたまま、電源につないでおく**（画面は暗くなってもかまいません。ふたは閉じない）。スリープの設定を変える必要はありません（集めている間は、UGC Analyzer が自動で Mac を眠らせないようにします。電池で動いているときは知らせます）
- 「続けて」のあとは **Claude（ChatGPT）も開いたまま**にしておく
- 途中で閉じてしまっても大丈夫。開けば続きから進みます（「続けて」のあとなら「〇〇の分析を続けて」ともう一度言う）
- Dock に Chrome のアイコンが出ていても閉じないでください（UGC Analyzer が使っています）

**集めている途中の様子**: 割れた音符のアイコンを押すと、1行目に「取得中: 〇〇 — コメントを取る 35/80本・残り約30分」のように出ます。
AI に「〇〇はどうなってる？」と聞いても教えてくれます。

## 直したいとき

| したいこと | AI に言うこと |
|---|---|
| このレポートだけ直す | 「〇〇のレポートの3章に音楽面の話を足して。サビ前のブレイクが効いてると思う」のように、そのまま（完成を知らせてきた会話の中なら、曲名は無くてよい） |
| ある界隈の話が浅い（掘り下げ） | 「〇〇のレポートの△△界隈のところ、なぜバズったのかが弱い。もっとコメントを取って掘り下げて」→ 取り足しに約25分 → 通知が出たら「〇〇の分析を続けて」→ 書き直しに10〜20分 |
| 界隈の分け方を変える（切り直し） | 「〇〇のレポート、△△界隈を2つに分けて」→ 書き直しに約25分（コメントが足りないときは、先に数分の取り足し → 通知 →「〇〇の分析を続けて」） |
| 界隈の確認を省く | 「〇〇の分析を続けて。界隈の確認はいらないので、そのまま最後まで書いて」（最初から: 「UGC Analyzer で〇〇／△△を分析して。界隈の確認はいらない」）。完成の知らせに使った界隈の一覧が出る |
| 「続けて」も送らずに任せる（Claude の Code タブ） | Claude アプリの Code タブで、ホームフォルダの「UGC Analyzer」を選んで「UGC Analyzer で〇〇／△△を分析して。界隈の確認はいらないので、そのまま最後まで書いて」。集め終わるのを Claude が待って、完成まで進む（待っている間は利用枠を使わない） |
| 今後ずっと変える | 「UGC Analyzer で、今後はレポートの文体をもっとくだけた感じにして」 |
| AI への指示そのものを変える | 「UGC Analyzer の〇〇の指示書をこう変えて」。または、割れた音符 →「指示書を編集」で直接書き換える（元に戻すボタンもあります） |
| 著者の新しい記事を取り込む | 「UGC Analyzer の知識ベースを更新して」（ふだんは週1回、自動で確かめています） |
| コメントへの返信も取る | 「UGC Analyzer で〇〇／△△を分析して。返信も取って」（ふだんは不要。取るとコメントの取得が2〜3割長くなります） |
| 再生の少ない動画のコメントも見る | 「UGC Analyzer で〇〇／△△を分析して。再生1万以上の動画も見て」（ふだんは、起点や大きなヒットなどのほかは再生10万以上の動画だけ見ます） |

## 困ったとき

- まず **割れた音符のアイコンの1行目** を見る（何をしているか・何を待っているかが出ます）
- 「止まっています」と出ていたら → 割れた音符 →「**止まった取得を続きから再開**」
- 「TikTok のログイン待ち」と出ていたら → 開いた Chrome でログインし直す
- 完成の知らせに「ウェブ検索が使えなかった」と出たら → 「＋」→「ウェブ検索」をオンにして、「〇〇のレポートの6章に、TikTok の外の数字（YouTube・チャートなど）を調べて足して」
- それでも直らなければ、**運営に LINE**（割れた音符 →「そのほか」→「取得の記録を開く」で出た画面の写真を送ってもらえると早いです）
