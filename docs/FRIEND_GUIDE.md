# UGC Analyzer の使い方（1枚）

TikTok で曲がどう広まったかを、あなたの AI（Claude か ChatGPT）が分析してレポートにします。
あなたがすることは、**AI に決まった一言を言うこと**だけです。

---

## 最初の1回（運営と LINE 通話しながら、20分ほど）

**用意するもの**: Mac（2020年以降の M1・M2・M3・M4）／Google Chrome／Claude の有料プラン（Pro 以上）か、ChatGPT（Mac のアプリ・macOS 14 以降。プランは〔運営が確かめ中〕）／
**ふだん使っていないメールアドレス**（TikTok の分析用アカウントを作るため。仕事や本アカウントのものは使わない）

1. **AI のアプリを入れる**: Claude の人は https://claude.ai/download 、ChatGPT の人は https://openai.com/chatgpt/download/ から入れて、ログインする
2. **UGC Analyzer を入れる**: LINE で届いたリンクから `UGC-Analyzer-….dmg` をダウンロードして開き、「UGC Analyzer」を「アプリケーション」へドラッグする
3. **UGC Analyzer を開く**: 「アプリケーション」の「UGC Analyzer」をダブルクリック
   - 「開いていません」と出たら「完了」→ **システム設定 → プライバシーとセキュリティ** → 下のほうの「**このまま開く**」→ パスワード → もう一度「**開く**」
4. **TikTok の分析用アカウントを作ってログイン**: UGC Analyzer が Chrome を開くので、TikTok の「新規登録」で用意したメールアドレスのアカウントを作り、ログインする
   - **スマホの TikTok アプリでは作らない**（ふだんのアカウントと同じスマホに入れないため）
   - 認証コードは、そのメールアドレスに届く
5. ログインが済むと、UGC Analyzer が自動で Claude（ChatGPT）につなぎ、「**Claude につなぎました**」（ChatGPT の人は「**ChatGPT につなぎました**」）と出るので「**開き直す**」を押す
   - 出てこないときは、画面右上の **割れた音符のアイコン** →「Claude につなぐ」（ChatGPT の人は「ChatGPT につなぐ」）→「開き直す」

これで準備は終わりです。割れた音符のアイコンは、いつも画面右上にいます（Mac を起動すると自動で立ち上がります）。

**ChatGPT の人へ**: 話しかけるのは ChatGPT のアプリの **Work** です（ふだんの Chat や、ブラウザの chatgpt.com では UGC Analyzer につながりません）。

## 分析するとき（決まった一言）

| いつ | AI に言うこと | そのあと |
|---|---|---|
| 1日目 | **「UGC Analyzer で〇〇（曲名）／△△（アーティスト名）を分析して」** | 「UGC Analyzer で」を付けないと、AI はふだんどおりに答えます（分析は始まりません）。付けると、Mac が TikTok でその曲の楽曲ページを探し（数十秒）、AI が「このページで集めます」と見せてそのまま始めます（同じ曲の sped up 版などがあれば、合わせて集めます）。そこから **13時間前後**、Mac が TikTok から集めます。ページが違っていたら「〇〇の取得をやめて、このページでやり直して」と URL を渡せば直せます |
| 終わったら | **「〇〇の分析を続けて」** | 「界隈（どんな人たちが使ったか）の案」が出るので、「OK」か、直したいところを言う。そこから **1.5〜3時間** で完成 |
| 完成したら | （何も言わなくてよい） | AI がレポートのリンクを出します。割れた音符 →「**レポートのフォルダを開く**」でも見られます |

**集めている間・書いている間のお願い**

- **Mac を開いたまま、電源につないでおく**（画面は暗くなってもかまいません。ふたは閉じない）。スリープの設定を変える必要はありません（集めている間は、UGC Analyzer が自動で Mac を眠らせないようにします。電池で動いているときは知らせます）
- 2日目は **AI のアプリ（Claude か ChatGPT）も開いたまま**にしておく
- 途中で閉じてしまっても大丈夫。開けば続きから進みます（2日目は「〇〇の分析を続けて」ともう一度言う）
- Dock に Chrome のアイコンが出ていても閉じないでください（UGC Analyzer が使っています）

**集めている途中の様子**: 割れた音符のアイコンを押すと、1行目に「取得中: 〇〇 — コメントを取る 35/197本・残り約8時間」のように出ます。
AI に「〇〇はどうなってる？」と聞いても教えてくれます。

## 直したいとき

| したいこと | AI に言うこと |
|---|---|
| このレポートだけ直す | 「〇〇のレポートの3章に音楽面の話を足して。サビ前のブレイクが効いてると思う」のように、そのまま（完成を知らせてきた会話の中なら、曲名は無くてよい） |
| 今後ずっと変える | 「UGC Analyzer で、今後はレポートの文体をもっとくだけた感じにして」 |
| AI への指示そのものを変える | 「UGC Analyzer の〇〇の指示書をこう変えて」。または、割れた音符 →「指示書を編集」で直接書き換える（元に戻すボタンもあります） |
| 著者の新しい記事を取り込む | 「UGC Analyzer の知識ベースを更新して」（ふだんは週1回、自動で確かめています） |
| コメントへの返信も取る | 「UGC Analyzer で〇〇／△△を分析して。返信も取って」（ふだんは不要。取るとコメントの取得が2〜3割長くなります） |
| 再生の少ない動画のコメントも見る | 「UGC Analyzer で〇〇／△△を分析して。再生1万以上の動画も見て」（ふだんは、起点や大きなヒットなどのほかは再生10万以上の動画だけ見ます） |

## 困ったとき

- まず **割れた音符のアイコンの1行目** を見る（何をしているか・何を待っているかが出ます）
- 「止まっています」と出ていたら → 割れた音符 →「**止まった取得を続きから再開**」
- 「TikTok のログイン待ち」と出ていたら → 開いた Chrome でログインし直す
- それでも直らなければ、**運営に LINE**（割れた音符 →「そのほか」→「取得の記録を開く」で出た画面の写真を送ってもらえると早いです）
