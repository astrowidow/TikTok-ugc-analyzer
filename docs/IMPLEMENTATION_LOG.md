| # | 決めたこと | 理由 |
|---|---|---|
| D1 | 本番 venv（Python 3.14.3）に `mcp==2.2.0` を足す。3.12 の別環境は使わない | `pip install mcp --dry-run` で cp314 の wheel が全部そろい、既存パッケージの入れ替えが0件だったため。控え: Windows `C:\Users\astrowidow\ugc-work\prod-venv-freeze-20261001.txt` |
| D2 | `requirements.txt` は `mcp>=2.2,<3`。**2.x は 1.x と書き方が違う**（`FastMCP` → `MCPServer`、仕様 2026-07-28 対応） | pip の既定が 2.x になったため。README（2.2.0 同梱）と公式文書 `py.sdk.modelcontextprotocol.io/run/asgi/` で載せ方を確認 |
| D3 | 秘密の URL の振り分けは、FastAPI に足す**一番外側の ASGI ミドルウェア**で `/mcp/<秘密>` を受け、`session_manager.handle_request` に直接渡す（Starlette の Mount は使わない） | `handle_request` はパスを見ない。Mount だとパスの書き換えと末尾スラッシュのリダイレクトが絡む。一番外側なので既存の Basic 認証（BaseHTTPMiddleware）を通らない。`main.py` の Basic 認証にも `/mcp/` の除外を1行足す（接続口が読めなかったときに 401 でなく 404 になるだけ） |
