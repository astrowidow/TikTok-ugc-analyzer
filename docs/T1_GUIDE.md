## これで確かめること

Claude デスクトップアプリに**サービスの接続（コネクタ）を1つ足すだけ**で、
「シルエットの分析を続けて」の**一言から最後まで**、AI が勝手に回るか。

試作の中身は「2回目の着席」の縮小版で、仕事は13個です:
分類軸の案 → **★界隈の確認（あなたが答える）** → ラベル付け 30本×7回 → コメント分析 3本 → 完了。
AI の作業時間は 30〜60分の見込みです（読めない。これも測る）。

あなたが答えるのは★の1回だけの予定です。

## 準備（最初の1回だけ。5分）

### 1. 接続の URL を手元に出す

Mac のターミナルで:

```
grep UGC_MCP_URL ~/.tiktok-ugc-win-credentials
```

`UGC_MCP_URL=` の後ろ（`https://giblet-squishy-icing.ngrok-free.dev/mcp/…`）が、あなた専用の接続の URL です。
**この URL は人に見せない・どこにも貼らない**（知っている人は誰でもあなたの分析を読み書きできます。TikTok や Windows 機には届きません）。

### 2. Claude デスクトップアプリにコネクタを足す

1. Claude デスクトップアプリ → **設定** → **コネクタ** → **カスタムコネクタを追加**
2. 名前: `UGC Analyzer（試作）`
3. URL: 手順1の URL（`https://` から最後まで）
4. 詳細設定（OAuth のクライアント ID など）は**空のまま** → 追加

追加に失敗して「認証」の話が出たら、そこで止めて私に教えてください（サービス側で1か所直す案があります。作業記録の D9）。

### 3. 道具の許可を「常に許可」にする

設定 → コネクタ → `UGC Analyzer（試作）` を開き、道具4つ（status / next_task / submit / read）を**常に許可**にする。
これをしないと、AI が結果を返すたびに許可を聞いてきて止まります。

### 4. 使用量をメモする

設定 → **使用量**（Usage）で、**5時間の枠の %** と **週の枠の %** をメモ。日時も。

## 本番（着席）

### 5. Cowork で一言だけ打つ

Cowork を開き、チャット欄の「＋」（またはツールの一覧）で `UGC Analyzer（試作）` が**オン**になっているのを確かめてから、

> **シルエットの分析を続けて**

とだけ打つ（説明は足さない。一言で回るかを見るため）。打った時刻をメモ。

### 6. 界隈の案が出たら答える

AI が「KANA-BOON「シルエット」の界隈の案です。①… ⑭… 分け方を変えたいところはありますか？」と聞いてきます。

- 今回は、**明らかにおかしい所が無ければ「OK」**で（界隈の一致率を前回の試験と比べるため。直した場合は比べられない）
- 直したいときは普通の言葉で（例: 「⑦はタレントとインフルエンサーで分けて。あとは OK」）

### 7. 答えたらアプリを閉じてみる

AI が「ここから先は確認なしで進めます」と言ったら、**アプリを閉じる**（閉じても裏で続くかを見る）。
30分〜1時間後にアプリを開き、会話がどこまで進んだかを見る。

### 8. 完了（または止まった）を見て、使用量をもう一度メモ

AI が「試作の仕事は全部終わりました」と言えば完了です。止まっていたら、そのときの画面の最後の数行を控えてください。
設定 → 使用量 の **5時間の枠の %・週の枠の %** をもう一度メモ。

`output\analyses\silhouette-proto\state\task_log.jsonl`）。あなたのメモと合わせて、枠の消費（T3）を見積もります。

## うまくいかなかったとき

| 起きたこと | まず試すこと | それでも駄目なら |
|---|---|---|
| 一言では回らない（AI が何をするか聞いてくる・道具を使わない） | 最初の一言を「**接続の指示に従って、シルエットの分析を続けて**」にする | プラグイン（定型の指示を入れる箱）を足す案に切り替える。私に教えてください |
| 仕事の途中で毎回「続けますか？」と聞いてくる | 「確認せずに最後まで続けて」と1回言う | 回数を記録してください（指示書の書き方を直します） |
| 閉じると止まる | 閉じずに待つ。または、止まったところで「続けて」と言う（続きから再開します。やり直しにはなりません） | 「続けて」を何回言ったかを記録 |
| 画像（サムネのシート）を読めない | そのまま続けてもらう（文字の情報だけでも分類はできる） | シートを文字の説明に置き換える形に変えます |
| 利用枠に当たった | 枠が戻ってから「シルエットの分析を続けて」 | どの仕事で当たったかを記録 |
| 「サービス側のエラー」と出た | 少し待って「続けて」 | Web サービスが落ちている可能性。私に教えてください |
