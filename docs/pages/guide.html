UGC ANALYZER　使い方

UGC Analyzer の
始め方と頼み方

TikTok で曲がどう広まったかを、あなたが使っている Claude か ChatGPT が、レポートにします。あなたがすることは、Claude（ChatGPT）に決まった一言を送ることと、そのあいだ Mac を開いたままにしておくことだけです。

はじめの準備

最初の1回だけです。上から順に進めれば、ひとりでできます。

用意するもの

  • Mac2020年以降の M1・M2・M3・M4 のもの
  • Google Chrome
  • Claude か ChatGPT（どちらか1つ）Claude の人は Mac の Claude アプリ（有料プランの Pro 以上が要ります）。ChatGPT の人は Mac の ChatGPT アプリ（macOS 14 以降。有料プランの Plus 以上をおすすめします。無料プランでも動きますが、選べるモデルが軽く、レポートの質がかなり落ちます）
  • TikTok の分析専用のサブアカウント分析のためだけに使う、ふだんとは別の TikTok のアカウントです。ふだんのアカウントは使いません。持っていない人は、手順4で作ります（そのための、ふだん使っていないメールアドレスか、ふだんの TikTok に使っていない Google アカウントを1つ用意してください）

やること（6つ）

  1. Claude（または ChatGPT）を Mac に入れて、ログインする

    Claude の人は claude.ai/download、ChatGPT の人は openai.com/chatgpt/download からアプリをダウンロードして開くと、最初に「ログイン」の画面が出ます。ふだん Claude や ChatGPT を使っているアカウント（メールアドレスや Google アカウント）で入ってください。アカウントが無ければ、ここで作ります。

  2. UGC Analyzer を入れる

    下のボタンを押すと、UGC-Analyzer.dmg というファイル（60MB ほど）がダウンロードされます。

    UGC Analyzer をダウンロード

    ダウンロードしたファイル（「ダウンロード」フォルダにあります）をダブルクリックします。小さな窓に「UGC Analyzer」と「アプリケーション」の2つが並ぶので、「UGC Analyzer」を「アプリケーション」の上までドラッグして離します。

  3. UGC Analyzer を開く（最初の1回だけ、ひと手間あります）
    1. Finder の「アプリケーション」フォルダで、「UGC Analyzer」をダブルクリックします。
    2. 警告が出ます。運営が Apple に登録していないアプリなので出る警告で、壊れているわけではありません。「完了」を押して、いったん閉じます。

    画面の見本

    “UGC Analyzer”は開いていません

    Apple は、“UGC Analyzer”に…（中略）…検証できませんでした。

    完了ゴミ箱に入れる

    「完了」を押す。「ゴミ箱に入れる」は押さない

    1. 画面左上のりんごマーク →「システム設定」→ 左の列の「プライバシーとセキュリティ」を開きます。
    2. 右側をいちばん下までスクロールすると、次のような一文があります。その横の「このまま開く」を押します。

    画面の見本（プライバシーとセキュリティのいちばん下）

    “UGC Analyzer”は…ブロックされました。

    このまま開く
    1. Mac のパスワード（または指紋）を入れます。もう一度確認が出たら「開く」を押します。
    2. 開くと、次のように聞かれます。UGC Analyzer が動かす Chrome のための確認です。「許可」を押します。

    画面の見本

    “UGC Analyzer”がローカルネットワーク上のデバイスを見つけることを許可しますか?
    許可しない許可

    「許可」を押す

    このひと手間は最初の1回だけです。次からは、ダブルクリックだけで開きます。

  4. TikTok にサブアカウントでログインする

    UGC Analyzer が開くと、Chrome が自動で立ち上がって TikTok のログイン画面が出ます。そこで、分析専用のサブアカウントでログインします。ふだんのアカウントではログインしないでください。

    サブアカウントを持っていない人は、同じ画面で「登録」を選び、ふだん使っていないメールアドレスでアカウントを作ってから、ログインします。確認のコードは、そのメールアドレスに届きます。

    確認のコードが届かない・「期限切れ」と出て先に進めないときは、登録の画面で「Google で続ける」を選べば作れます。ふだんの TikTok に使っていない Google アカウントを選んでください（ふだんの TikTok とつながった Google アカウントだと、ふだんのアカウントに入ってしまいます）。

    サブアカウントは、スマホの TikTok アプリで作ったりログインしたりしないでください。ふだんのアカウントと同じスマホに入れないためです。

  5. 「つなぎました」と出たら「開き直す」を押す

    ログインが済むと、UGC Analyzer が自動で Claude（ChatGPT）につなぎ、次のような小さな窓が出ます。「開き直す」を押すと、Claude（ChatGPT）が一度閉じて自動で開き直し、使えるようになります。

    画面の見本（ChatGPT の人は「ChatGPT につなぎました」）

    Claude につなぎました

    Claude を開き直すと、UGC Analyzer が使えるようになります。今すぐ開き直しますか？（話している途中の会話は保存されています）

    あとで自分で開き直す

    Claude で作業中のものがあると、Claude が次のように聞いてきます。「このまま終了」を押します（話していた会話は消えません）。Claude が閉じると、UGC Analyzer が自動で開き直します。開かないときは、Claude を自分で開いてください。

    画面の見本（Claude で作業中のものがあるときだけ）

    Claudeはまだ作業中です

    Claudeは1件のセッションで作業中です。今終了すると、その作業が中断されます。

    このまま終了Claudeの作業完了を待つキャンセル

    「このまま終了」を押す

  6. モデルを選ぶ

    分析は長く複雑な仕事なので、賢いモデルを選んでください。入力欄のまわりにあるモデルの選び（ChatGPT は Work の画面の入力欄の下）で選びます。

    • Claude の人Opus 5.5、推論の強さは Medium 以上
    • ChatGPT の人GPT-6.1 Sol、推論の強さは Medium 以上（Plus 以上で選べます）。もっと確実にしたいときは GPT-6 Astra（Plus では利用枠の減りが速くなります）

    運営は Claude の Opus 5.5・推論の強さ Extra high で使っています。軽いモデルや弱い推論にすると、利用枠の減りは小さくなりますが、レポートの質は落ちます。

これで準備はおしまい

画面右上のメニューバーにいる割れた音符のアイコンが UGC Analyzer です。Mac を起動すると自動で立ち上がります。

アイコンが見当たらないときは、「割れた音符のアイコンが見当たらないとき」のとおりに直してください（MacBook では、メニューバーに入りきらずに隠れることがよくあります）。

ChatGPT の人へ：話しかけるのは ChatGPT アプリの Work の画面です。ふだんの Chat の画面や、ブラウザの chatgpt.com では UGC Analyzer につながりません。

Claude は「集め終わったら、このまま自動で続けます」と返して待ちます。そのあいだ Mac と Claude は開いたまま・電源につないだままにしてください。界隈の案を見て決めたいときは「界隈の確認はいらない」を外せば、案が出たところで聞いてきます。

待っている間は、Claude の利用枠を使いません。Code タブはコマンドを実行できる画面です。UGC Analyzer の道具と、集め終わるのを待つ命令（ugc-wait）と、ウェブ検索（曲の情報や TikTok の外の数字を調べるため）は許可してあります。それ以外のことで許可を聞かれたら、許可しないで大丈夫です。

割れた音符のアイコンが見当たらないとき

メニューバーのアイコンが多いと、入りきらない分は何の印もなく隠れます（MacBook でよく起きます）。新しく入れた UGC Analyzer のアイコンは、いちばん隠れやすい場所に置かれます。まず、りんごマーク →「システム設定」→ 左の列の「メニューバー」の「メニューバーに追加することを許可」で、「UGC Analyzer」がオンになっているかを確かめます。オンなのに出ないときは、次のどれかで場所を空けてください。上ほど簡単です。

1. 使っていないアイコンを消す

りんごマーク →「システム設定」→ 左の列の「メニューバー」を開きます。

  • 「メニューバーに追加することを許可」の一覧で、使っていないアプリをオフにする（UGC Analyzer はオンのまま）
  • 「メニューバーコントロール」の一覧で、Wi‑Fi や Bluetooth など見なくてよいものを「メニューバーに非表示」にする
  • 「時計のオプション…」で「日付を表示」をオフにすると、時計が短くなる

2. アイコンの間隔を詰める

⌘（command）とスペースを一緒に押し、「ターミナル」と打って return で開きます。下の1行をコピーしてターミナルに貼り、return を押します。そのあと、りんごマーク →「再起動…」で Mac を再起動すると、アイコンの間隔が半分になります。

ターミナルに貼る（間隔を詰める）

defaults -currentHost write -globalDomain NSStatusItemSpacing -int 8; defaults -currentHost write -globalDomain NSStatusItemSelectionPadding -int 8

元に戻すときは、この1行を同じように貼ってから再起動します。Mac が集めている途中なら、終わってから再起動してください。

ターミナルに貼る（元に戻す）

defaults -currentHost delete -globalDomain NSStatusItemSpacing; defaults -currentHost delete -globalDomain NSStatusItemSelectionPadding

3. 整理アプリ Thaw を入れる（無料）

あまり使わないアイコンを隠して、要るものだけをメニューバーに出せるアプリです（運営が作ったものではありません。macOS 26 以降で使えます）。

Thaw をダウンロード

UGC Analyzer と同じように「アプリケーション」へドラッグして開きます。最初に「アクセシビリティ」の許可を聞かれたら、許可します。割れた音符のアイコンは、隠さずに見える側に置いてください。

守ってほしいこと

  • TikTok はサブアカウントだけでログインする。ふだんのアカウントは使わない。サブアカウントはスマホの TikTok アプリに入れない
  • パスワードは誰にも教えない。運営にも教えないでください。運営が聞くことはありません
  • 集めている間と書いている間は、Mac のふたを閉じない・電源につなぐ。Dock の Chrome も閉じない
  • 分析は AI の利用量をたくさん使います。Claude Pro の場合、5時間ごとの利用枠のうち、第1版で約7割、掘り下げで約3割、切り直しで約4割が目安です。これは運営の環境（Claude Max 5x・モデル Opus 5.5・推論の強さ Extra high）で使った量を、Pro に換算した見積もりです（曲の情報や TikTok の外の数字をウェブで調べる分を含む）。推論の強さを Medium にすれば、減り方はもっと小さくなる見込みです。同じ5時間のうちに第1版と直しを続けて頼むと枠を超えやすいので、直しは枠が戻ってから頼むのがおすすめです。書いている途中で上限に届いたら、上限が戻ってから「〇〇の分析を続けて」で続きから進みます
  • UGC Analyzer を使いたくないときは、「UGC Analyzer で」を付けずに話しかければ、いつもの AI のままです

運営への連絡

わからないこと・変だと思ったことは、何でも LINE でどうぞ。「レポートのここが変」という感想も助かります。

運営から「UGC Analyzer を新しくしました」と連絡が来たら、割れた音符 →「終了」→ 手順2と同じボタン（UGC Analyzer をダウンロード。いつも新しい版が落ちてきます）から .dmg を落として、最初と同じように「アプリケーション」へドラッグしてください。「置き換える」を選んで OK です。データとログインはそのまま残ります。

実際の会話とできあがったレポートは「きゃわぽっぴんどぅー分析の実例」で、手を加えずに見られます。

時間は UGC Analyzer 0.7.5 での実測をもとにした目安です。曲の大きさや AI の混み具合で前後します。
