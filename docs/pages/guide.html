UGC ANALYZER　使い方

UGC Analyzer の
始め方と頼み方

TikTok で曲がどう広まったかを、あなたの AI（Claude か ChatGPT）がレポートにします。あなたがすることは、AI に決まった一言を送ることと、そのあいだ Mac を開いたままにしておくことだけです。

はじめの準備

最初の1回だけです。上から順に進めれば、ひとりでできます。

用意するもの

  • Mac2020年以降の M1・M2・M3・M4 のもの
  • Google Chrome
  • AI のアプリ（どちらか1つ）Claude の人は Mac の Claude アプリ（有料プランの Pro 以上が要ります）。ChatGPT の人は Mac の ChatGPT アプリ（macOS 14 以降。無料プランでも動きますが、レポートの質がかなり落ちるので、有料プランをおすすめします）
  • TikTok の分析専用のサブアカウント分析のためだけに使う、ふだんとは別の TikTok のアカウントです。ふだんのアカウントは使いません。持っていない人は、手順4で作ります（そのための、ふだん使っていないメールアドレスを1つ用意してください）
  • 運営から届いた UGC Analyzer のダウンロードリンク

やること（5つ）

  1. AI のアプリを入れて、ログインする

    Claude の人は claude.ai/download、ChatGPT の人は openai.com/chatgpt/download からアプリをダウンロードして開くと、最初に「ログイン」の画面が出ます。ふだん Claude や ChatGPT を使っているアカウント（メールアドレスや Google アカウント）で入ってください。アカウントが無ければ、ここで作ります。

  2. UGC Analyzer を入れる

    運営から届いたリンクから .dmg という種類のファイルをダウンロードして、ダブルクリックします。小さな窓に「UGC Analyzer」と「アプリケーション」の2つが並ぶので、「UGC Analyzer」を「アプリケーション」の上までドラッグして離します。

  3. UGC Analyzer を開く（最初の1回だけ、ひと手間あります）
    1. Finder の「アプリケーション」フォルダで、「UGC Analyzer」をダブルクリックします。
    2. 警告が出ます。運営が Apple に登録していないアプリなので出る警告で、壊れているわけではありません。「完了」を押して、いったん閉じます。

    画面の見本

    “UGC Analyzer”は開いていません

    Apple は、“UGC Analyzer”に…（中略）…検証できませんでした。

    完了ゴミ箱に入れる

    「完了」を押す。「ゴミ箱に入れる」は押さない

    1. 画面左上のりんごマーク →「システム設定」→ 左の列の「プライバシーとセキュリティ」を開きます。
    2. 右側をいちばん下までスクロールすると、次のような一文があります。その横の「このまま開く」を押します。

    画面の見本（プライバシーとセキュリティのいちばん下）

    “UGC Analyzer”は…ブロックされました。

    このまま開く
    1. Mac のパスワード（または指紋）を入れます。もう一度確認が出たら「開く」を押します。

    このひと手間は最初の1回だけです。次からは、ダブルクリックだけで開きます。

  4. TikTok にサブアカウントでログインする

    UGC Analyzer が開くと、Chrome が自動で立ち上がって TikTok のログイン画面が出ます。そこで、分析専用のサブアカウントでログインします。ふだんのアカウントではログインしないでください。

    サブアカウントを持っていない人は、同じ画面で「登録」を選び、ふだん使っていないメールアドレスでアカウントを作ってから、ログインします。確認のコードは、そのメールアドレスに届きます。

    サブアカウントは、スマホの TikTok アプリで作ったりログインしたりしないでください。ふだんのアカウントと同じスマホに入れないためです。

  5. 「つなぎました」と出たら「開き直す」を押す

    ログインが済むと、UGC Analyzer が自動であなたの AI につなぎ、次のような小さな窓が出ます。「開き直す」を押すと、AI のアプリが一度閉じて自動で開き直し、使えるようになります。

    画面の見本（ChatGPT の人は「ChatGPT につなぎました」）

    Claude につなぎました

    Claude を開き直すと、UGC Analyzer が使えるようになります。今すぐ開き直しますか？（話している途中の会話は保存されています）

    あとで自分で開き直す

これで準備はおしまい

画面右上のメニューバーにいる割れた音符のアイコンが UGC Analyzer です。Mac を起動すると自動で立ち上がります。

ChatGPT の人へ：話しかけるのは ChatGPT アプリの Work の画面です。ふだんの Chat の画面や、ブラウザの chatgpt.com では UGC Analyzer につながりません。

AI のアプリを開いて、こう送ります。〇〇は曲名、△△はアーティスト名です。

AI に送る

いちばん大事なのは、頭の「UGC Analyzer で」です。これが無いと、AI はふだんどおりに答えるだけで、分析は始まりません。Claude で「道具を使ってよいか」と聞かれたら「常に許可」を押してください。

待っているあいだのお願い

Mac が動画とコメントを集めている間（約2〜3時間）と、AI がレポートを書いている間（30〜45分）
  • Mac は開いたまま・電源につないだまま（画面が暗くなるのは OK。ふたは閉じない）
  • Dock に Chrome が出ていても閉じない（UGC Analyzer が使っています）
  • AI がレポートを書いている間は、AI のアプリも開いたまま
  • ふだんどおり Mac を使っていて大丈夫です

途中の「OK」のかわりに、直しを頼んでもいい

界隈の案を見て分け方が気になったら、「OK」のかわりに、思ったことをそのまま送れば大丈夫です。AI は直した分け方でそのまま書き進めます。

あなた

ダンスの界隈を、外で踊ってる人と室内で踊ってる人に分けて

あなた

アニメ好きの界隈とコスプレの界隈は、ひとつにまとめて

界隈の確認を省きたいとき

界隈の案を見ずに最後まで書いてほしいときは、「界隈の確認はいらない」と添えます。AI は止まらずに完成まで進み、完成の知らせに、使った界隈の一覧が出ます。分け方は、あとからでも切り直せます（直す・深める）。何も言わなければ、今までどおり1回だけ聞いてきます。

あなた（「続けて」のとき）

〇〇の分析を続けて。界隈の確認はいらないので、そのまま最後まで書いて

あなた（最初に頼むとき）

UGC Analyzer で〇〇／△△を分析して。界隈の確認はいらない

（準備中）「続けて」も送らずに、完成まで任せる

いまは、Mac が集め終わったあとに、あなたが「続けて」と送る必要があります。Claude アプリの Code タブを使うと、集め終わるのを Claude が待って、そのまま完成まで進められるようになる見込みです。運営で確かめてから、やり方をここに書きます。

こんなときは、こう送る

今どうなっているか知りたい
「きゃわぽっぴんどぅーはどうなってる？」
AI が選んだ楽曲ページが違う
「きゃわぽっぴんどぅーの取得をやめて、このページでやり直して https://www.tiktok.com/music/…」

できたレポートを直す・深める

レポートを読んで「ここをこうしたい」と思ったら、そのまま AI に送れば OK です。直す前の版も消えずに残ります。完成を知らせてきた会話の中なら、曲名は省いても通じます。

文章や考察を直したい・足したい

その場で書き直します。

待ち時間: その場で
あなた（例）

きゃわぽっぴんどぅーのレポートの3章に、音楽面の話を足して。サビ前のブレイクが効いてると思う

ある界隈の話が浅い・もっと知りたい（掘り下げ）

その界隈のコメントを Mac が取り足してから、書き直します。AI は「約25分かかります」と返していったん止まるので、Mac に「取り足しが終わりました」と通知が出たら「〇〇の分析を続けて」と送ります。

待ち時間: 取り足しに約25分 → 「続けて」→ 書き直しに10〜20分
あなた（実際に送った言葉）

きゃわぽっぴんどぅーのレポートで、生活情報系（グルメ・レシピ・お出かけ）のBGMの界隈のところ、「BGM化は曲への関心にはつながらなかった」と書いてあるけど、根拠が弱い気がする。もっとコメントを取って掘り下げて

界隈の分け方そのものを変えたい（切り直し）

界隈を分け直して、レポートを書き直します。新しい界隈でコメントが足りないときは、AI が最初の返事で「約〇分かかります。通知が出たら『〇〇の分析を続けて』と頼んでください」と教えてくれるので、そのとおりにします。

待ち時間: 書き直しに約25分（コメントが足りないときは、先に数分の取り足し →「続けて」）
あなた（実際に送った言葉）

きゃわぽっぴんどぅーのレポートの界隈の分け方を変えたい。「他のアイドル」に、地下アイドルやコンカフェ・アイドル志望の人と、=LOVEや関西ジュニアみたいな事務所のメジャーなアイドルが混ざってる。この2つは分けて、界隈の切り直しからやり直して

まずは画面右上の割れた音符のアイコンを押して、いちばん上の行を見てください。今何をしているかが出ています（例:「取得中: きゃわぽっぴんどぅー — コメントを取る 35/80本・残り約30分」）。

「UGC Analyzer で〜」と送ったのに、AI がふつうに答えるだけ
割れた音符 →「Claude につなぐ」（ChatGPT の人は「ChatGPT につなぐ」）→ AI のアプリを開き直す。ChatGPT の人は Work の画面で送っているかも確かめる
いちばん上の行が「止まっています」

「続けて」と送ったら「まだ集めている途中」と言われた
正常です。通知が出るまで待ってから、もう一度「〇〇の分析を続けて」
「電池で動いています」と知らせが出た
電源につなぐ
Mac や AI のアプリを閉じてしまった
開くだけで OK。書いている途中だったら、もう一度「〇〇の分析を続けて」
レポートのリンクをなくした

それでも直らなければ、運営に LINE してください。割れた音符 →「そのほか」→「取得の記録を開く」で出た画面の写真を一緒に送ってもらえると早いです。

守ってほしいこと

  • TikTok はサブアカウントだけでログインする。ふだんのアカウントは使わない。サブアカウントはスマホの TikTok アプリに入れない
  • パスワードは誰にも教えない。運営にも教えないでください。運営が聞くことはありません
  • 集めている間と書いている間は、Mac のふたを閉じない・電源につなぐ。Dock の Chrome も閉じない
  • 分析は AI の利用量をたくさん使います。Claude Pro の場合、5時間ごとの利用枠のうち、第1版で約6割、掘り下げで約2割、切り直しで約4割が目安です。これは運営の環境（Claude Max 5x・モデル Opus 5.5・推論の強さ Extra high）で使った量を、Pro に換算した見積もりです。軽いモデルや弱めの推論で使えば、減り方はもっと小さくなる見込みです。書いている途中で上限に届いたら、上限が戻ってから「〇〇の分析を続けて」で続きから進みます
  • UGC Analyzer を使いたくないときは、「UGC Analyzer で」を付けずに話しかければ、いつもの AI のままです

運営への連絡

わからないこと・変だと思ったことは、何でも LINE でどうぞ。「レポートのここが変」という感想も助かります。

運営から「UGC Analyzer を新しくしました」と連絡が来たら、割れた音符 →「終了」→ 届いた新しい .dmg を、最初と同じように「アプリケーション」へドラッグしてください。「置き換える」を選んで OK です。データとログインはそのまま残ります。

実際の会話とできあがったレポートは「きゃわぽっぴんどぅー分析の実例」で、手を加えずに見られます。
