UGC ANALYZER 0.9.0 の案　見え方の見本

新しい版が、
自分で入るようにする

新しい版が出ると、UGC Analyzer が自分で見つけて入れ替えます。友達がすることは、窓のボタンを1回押すだけです。Claude（ChatGPT）を閉じているあいだなら、それも要りません。

このページは見本です。本物のアプリの画面ではありません。見え方と流れに OK をもらってから作り、運営の Mac で通してから友達に出します。

友達がすること
0回か1回窓の「今すぐ新しくする」を押すだけ
届くまで
3時間以内運営が「友達に出して」と言ってから（Mac が起きていれば）
入れ替えの時間
1分ほどClaude の開き直しを含めて（見込み）
最初の1回
0.9.0 だけ手で0.8.1 にはこの仕組みが無いので、今までの手順で入れる

友達の Mac で起きること

新しい版を見つけてから入れ替えるまで。場合は3つあります。

  1. 運営が「友達に出して」と言うと、その版が友達向けの最新になります。
  2. UGC Analyzer が、アプリを開いたとき・Mac が起きたとき・3時間おきに新しい版を見に行きます。
  3. 見つけたら、裏で落として確かめておきます（60MB ほど。友達の目には何も出ません）。
  4. そのときの Mac の様子で、次の3つのどれかになります。
A　黙って入れ替え Claude も ChatGPT も閉じている

取得も、AI の作業もしていない

UGC Analyzer が自分で入れ替えて、通知を1つ出すだけ。友達がすることはなし

B　窓で聞く Claude（ChatGPT）を開いている

取得も、AI の作業もしていない

窓で聞く。「今すぐ新しくする」を押すと、入れ替えて Claude を開き直す。「あとで」なら、次に Claude を閉じたときに A になる

C　待つ 取得中・AI が書いている途中

取り足し・順番待ち・取り直しの予定も含む

終わるまで待つ。メニューに1行出すだけ。終わったら A か B になる。友達がすることはなし

3.「今すぐ新しくする」を押したあと

押したあとの順番:

  1. Claude が閉じます（作業中なら、左の窓が出ます）

  4. 下の通知が出たら完了です

5. うまく入れ替えられなかったとき

画面の見本：めったに出ない窓

自動で新しくできませんでした

いまの版（0.9.0）は、そのまま使えます。新しい版にするには、始め方のページの「新しい版にするとき」のとおりに、手で入れ替えてください（10分ほど）。

手順を開く 閉じる

入れ替えの途中で止まったときは、前の版に戻してから出します。UGC Analyzer が使えなくなることはありません。

UGC Analyzer を「アプリケーション」の外（「ダウンロード」など）から開いているときも、この窓になります。

手順書の書き直し

始め方のページの「新しい版にするとき」を、次の形にします。紙（1枚もの）も同じ中身にそろえます。

新しい版にするとき

UGC Analyzer は、新しい版が出ると自分で新しくなります（0.9.0 以降の版）。前から進めていた分析とレポートは、そのまま残ります。

Claude（ChatGPT）を閉じているとき 何もしなくて大丈夫です

UGC Analyzer が自分で新しくして、「UGC Analyzer を 〇〇 にしました」と通知を出します。

Claude（ChatGPT）を開いているとき 窓の「今すぐ新しくする」を押します

Claude が一度閉じて、1分ほどで開き直します。話していた会話は消えません。「Claudeはまだ作業中です」と出たら「このまま終了」を押します。「あとで」を押したときは、次に Claude を終了したときに新しくなります。

集めている途中・AI が書いている途中 終わってから新しくなります

途中で止めることはありません。何もしなくて大丈夫です。

割れた音符のメニューのいちばん下（「終了」の上）に、いまの版の番号が出ています。いまの版は UGC Analyzer 0.9.0 です。

0.8.1 までの版を使っている人（1回だけ）

0.8.1 までの版は、自分では新しくなりません。次のとおりに、1回だけ手で入れ替えてください（10分ほど）。0.9.0 にすれば、次からは自分で新しくなります。

  1. 割れた音符 →「終了」
  2. ボタンで UGC-Analyzer.dmg を落とし、「UGC Analyzer」を「アプリケーション」へドラッグ →「置き換える」（「両方とも残す」は押さない）
  3. 新しい UGC Analyzer を開く（「開いていません」と出たら、はじめの準備と同じように「このまま開く」）
  4. Claude（ChatGPT）を ⌘Q で終了して、開き直す

運営（ユーザーさんと Claude）の流れ

試していない版が友達に届かないように、届けるのはユーザーさんが「友達に出して」と言ったときだけにします。

今まで

  1. Claude が直して出す（友達のリンクも、その版になる）
  2. ユーザーさんが LINE で入れ替えを頼む
  3. 友達が6つの手順で入れ替える

これから

  1. Claude が直して、試し版として出す（友達には届かない。リンクも前の版のまま）
  2. 運営の Mac が試し版を受け取り、友達と同じ自動の入れ替えを先に通る
  3. ユーザーさんが試して「0.9.1 を友達に出して」と言う
  4. Claude が友達向けに切り替え、始め方のページの「いまの版」を直して公開し直す
  5. 3時間以内に、友達の Mac が自分で新しくなる

細かい決め

変えたいところがあれば言ってください。

新しい版を見に行くアプリを開いたとき・Mac が起きたとき・3時間おき。メニューの「新しい版を確かめる…」を押したとき
窓を出す回数1日1回まで。「あとで」を押したら次の日まで出さない。メニューからはいつでも
作業中とみなすとき取得・取り足しの途中、順番待ち、止まって自動で取り直す予定のもの（今の運営の入れ替えと同じ見方）。AI が UGC Analyzer の道具を最後に使ってから15分以内。Claude の Code タブで待っているとき
前の版データのフォルダに1つだけ控えを残す。ゴミ箱には入れない（友達が戻してしまわないように）
新しい版を落としたあと版の番号と大きさを確かめ、新しい版が起動できるかを試してから入れ替える。だめなら入れ替えない
古い版に戻すしない（新しい版の番号のときだけ入れ替える）。まずい版を出したときは、直した版を出す
自動の入れ替えを止める友達向けの切り替えは作らない（選ぶところを増やさない）

作るときに確かめること

  • アプリが自分で落とした版では、「開いていません」（このまま開く）が出ないこと。Mac がダウンロードの印を付けないので、出ないはずです
  • Mac の「アプリの管理」の確認（「UGC Analyzer がほかのアプリを変更しようとしています」）が出るか。出るなら、最初の1回だけ「許可」してもらう見本と手順を足します
  • 入れ替えたあと、Claude の中の UGC Analyzer が新しい版で動くこと（開き直しが効く）
  • 取得中に新しい版が届いても、終わるまで待つこと。取得の途中のデータが壊れないこと
  • 運営の Mac で 0.8.1 →（手で）0.9.0 →（自動で）0.9.1 を、A・B・C の3つの場合で通すこと
