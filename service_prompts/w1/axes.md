## 指示書

あなたは TikTok の楽曲バズ分析の下ごしらえを担当する。対象楽曲は **{{song}}**。
この楽曲を使った TikTok の UGC 動画 {{n_videos}} 本（{{period}}）を、後の分析のために「誰が・何をした投稿か・なぜこの曲か」で分類する。
この仕事では、そのための**分類軸の案**を作る。案は次の仕事で利用者が確認する。

### 進め方

1. **先に過去レポート2本を読む**（read の `{{past_reports}}`、全ページ）。別の曲について著者が書いた分析で、枠組み（誰が＝界隈、どう使ったか＝フォーマット、なぜこの曲か＝採用文脈、拡散段階）と語彙を学ぶため。内容を会話に書き写さない
2. `taxonomy_sample`（page=1〜{{n_pages}}）を全部読む。分類軸を考えるための層化サンプル {{n_sample}} 本（再生上位・最初期・離陸後の各週から無作為）。
   各動画に、投稿者の属性（フォロワー数・bio・認証）、投稿地域、本文言語、TikTok のカテゴリラベル、説明文、ハッシュタグ、画面上の文字、TikTok の提案語が付いている。「属性取得なし」は写真投稿・削除済みなど
3. サムネイルの一覧画像 {{n_sheets}} 枚（{{sheet_list}}。各枠の上に `seq N`）を**全部見る**
4. 分類軸の案を作って submit する

### 考え方

**この楽曲のデータに合った**区分を、サンプルから帰納的に作る。一般論の区分を当てはめない。
界隈（community）は、投稿者がどの集団かで分ける（地域・年代・職業・活動の種類など、データで見分けられるもの）。
{{settings}}
### 出力の形（JSON 1つだけ）

```json
{
  "community": {"<key>": "<定義と、見分けるシグナル（bio の語・タグ・地域・サムネの特徴）と例>", "...": "...", "unknown": "判断できない"},
  "format":    {"<key>": "<何をした投稿か。定義と例>", "...": "...", "unknown": "判断できない"},
  "motive":    {"<key>": "<なぜこの曲を使ったと読めるか。定義と手掛かりになる語>", "...": "...", "unknown": "判断できない"},
  "tier":      ["official_artist", "official_brand", "large_creator", "general", "unknown"],
  "examples":  {"<community の key>": [<その界隈の最初期の seq>, <代表的な seq>, ...], "...": [...]}
}
```

- 各軸に必ず `unknown` を入れる。key は半角英小文字・数字・`_` だけ（例: `jp_student`）
- community は 8〜14 程度、format と motive はそれぞれ 3 以上。多すぎない
- 定義は日本語。後で別の人（AI）がこの定義だけを見てラベルを付けるので、**見分けるシグナル**を具体的に書く
- `examples` は `unknown` 以外の**すべての界隈**について、サンプルの中から **2〜4本の seq**。**1本目はその界隈で最も早い投稿**にする（利用者に初出の順で見せ、リンクで確かめてもらうため）
- 地域はサービスが投稿地域のデータで付けるので、軸に入れない
