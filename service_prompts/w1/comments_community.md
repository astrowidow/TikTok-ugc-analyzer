## 指示書

対象楽曲は **{{song}}**。界隈 **{{community}}**（{{community_def}}）の投稿についたコメントを**界隈まとめて**読み、
「この界隈がなぜこの曲を使ったか」「見た人はどう反応したか」の**大まかな傾向**をつかむ（{{i}}/{{n}} 界隈目）。
動画1本ずつの細かい分析は要らない。傾向をつかんだら、**それを確かめるために、特定の動画の具体的なコメントを読んで引用する**。

### 進め方

1. 下の「この界隈のコメント」を全ページ読む（read の `ccomments:{{community}}`、page=1〜{{n_pages}}。1ページ目は下にある）。各動画のいいねの多いコメントが並んでいる
2. 界隈全体の傾向（使った理由・反応の型・言語・段階による変化）を考える
3. 傾向を確かめるため、2〜4本の動画を選び、read の `comments:<seq>` でその動画のコメントを全部読む。傾向と違う反応があれば、傾向のほうを直す
4. 書いて submit する

反応の読み方の語彙は read の `kb:glossary`（F 章＝採用文脈・動機、H 章＝指標の読み方）。一度読めば次の界隈では読まなくてよい。

### 出力の形（Markdown）

`### {{community}}` で始め、次の小見出しをこの順に書く:

- `#### コメントの全体傾向`: この界隈の動画全体を通した反応の傾向（多い反応・少ない反応、言語、質問・ツッコミ・本家探しなど）
- `#### この界隈が曲を採用した文脈`: 動画の属性とコメントから
- `#### 段階による変化`
- `#### 具体例で確かめた引用`: 確かめた動画ごとに「seq N（@投稿者、日付、再生）」と、引用1〜3件（「『本文』（N いいね、cid 123…）」の形）。全部で3〜8件
- `#### ラベルとのずれ`: ラベルの採用文脈と、コメントから読める実態のずれ（無ければ「なし」）

コメントが少ない界隈は、分かることだけ書いて「根拠薄」と明記する。
