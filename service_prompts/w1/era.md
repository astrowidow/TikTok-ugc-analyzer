## 指示書

{{song}} の記事の5章「時代背景における本楽曲の立ち位置」の材料を作る。著者は過去の記事で、時代背景を次の型で書いている:
**この曲の型（著者のバズ曲の分類のどれか）→ 直近の同じ型の曲 → その型の流れ（いつから・どう変わってきたか）→ その流れの中で、この曲は何が同じで何が新しいか。**
著者の過去の記事を読み、この曲と**似た位置づけの曲**を踏まえて、この曲がどういう曲かを言い切る材料にする。**利用者に確認せず、決めて返す。**

### やること

1. 下の「この曲の分析の要約」と「著者のバズ曲の分類」から、この曲の型を決める（いちばん近い1つ。2つにまたがるなら主と副）。
   決めた理由を、この曲のデータ（界隈・使われ方・コメント）で
2. 下の「楽曲分析の記事の一覧」から、**似た位置づけの曲**（同じ型・似た界隈の渡り方・似たバズの形）を扱った記事を **2〜4本** 選び、
   `note:<file>` で読む。読むのは主に「時代背景」の章と「先に結論」「今回のヒットの核」
3. 下の「同じ時期の月報」から1〜3本を `note:<file>` で読み、この曲が伸びた時期に、ほかにどんな曲が流行っていたか（同じ型の曲はあったか）をつかむ
4. ウェブ検索が使えるなら、必要に応じて、同じ時期のチャート（Billboard JAPAN の TikTok Weekly Top 20 など）で同じ型の曲を確かめてよい

### 守ること

- 過去の記事の言い回しを写さない。曲名・アーティスト名・時期・型の名前は書いてよい
- この曲のデータで裏づけられないことを、この曲の主張にしない
- 出どころは記事の file 名（`2025-04-03_n…` の形）で残す（記事の本文には書かない。執筆の仕事が読む材料）
- 読んだ記事の中身を会話に書き写さない（利用枠を節約するため）

### 出力の形（Markdown）

次の見出しをこの順に。全体で 3,000 字まで。

- `### この曲の型`: 型の名前と、そう決めた理由（この曲のデータで）
- `### 似た位置づけの曲`: 1曲1項目。「曲名 / アーティスト（伸びた時期）— 何が似ていて、何が違うか（file 名）」
- `### 同じ時期の流行`: この曲が伸びた時期に流行っていた曲と、その中でのこの曲の目立ち方（file 名）
- `### この曲の立ち位置`: 5章で言い切る主張を2〜4個（「〜の流れの中で、〜という点が新しい」の形）
