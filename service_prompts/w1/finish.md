## 指示書

{{song}} の分析レポートのうち、下の「{{chapter_title}}」を、著者が note に**コピペするだけで公開できる原稿**に仕上げる（仕上げ {{i}}/{{n}}）。
**分析の内容・結論・数値・引用の文言は変えない。新しい主張を足さない。** 変えるのは体裁だけ。

### やること

- **内部の印を本文から全部消す**: `seq 57`、`cid 7551…`、ウェブで調べた事実の出どころの印（`[W3]`）、段階の ID（P1〜）、界隈などの key（`jp_student` のような英字）、ファイル名、「本データ」「先行工程」などの作業の言葉。読者はこの原稿しか見ない（調べた事実の出どころは、サービスが確認メモにまとめる）
- **YouTube の公式の動画**: 下の「ウェブで調べた事実の出どころ」に MV・公式音源など YouTube の公式の動画があり、本文がそれに触れていれば、その URL を**それだけの行**に置いてよい（note が埋め込みに変える）。ほかの出どころの URL は本文に貼らない
- **著者の名乗りを残さない**: 「こんにちは、山本です！」・執筆クレジット（「執筆：…」）・会社名（「弊社では」は「ここでは」などに）・お仕事募集の案内が残っていれば消す
- **見出しを端的に**: 見出し（`##`・`###`・【】）のかっこ書きの注釈は消す（「〜（インサイト）」→「〜」）。本文の（…）の補足も、決まった書き方（いいね数・動画の行）のほかは減らし、要るなら文にする
- **空けておく書き方を残さない**: 「ここは人の考察を入れる場所」「ここでは扱えない」のような、書けないことの断り書きは消す（その段落の言えることは残す）
- **作業の仕組みに触れた文を直す**: 「用語集でいう」「用語集の通り」「因果パターンで言えば」「文体ガイド」「知識ベース」「過去記事のカード」「ラベル付き」のような言い回しは、読者に向けた説明に言い換える（例:「用語集でいう『友人を召喚する口実』」→「いわば『友達を誘う口実』として機能した」）
- **集めた本数を主語にした文を直す**: 「今回集めた動画は〇本」「〇本中〇本」のような、こちらが集めた本数に寄りかかった文は、曲全体で起きたこととして言い換えるか消す（UGC 数は曲全体の数を使う）
- **動画の紹介**: 下の「動画の一覧」の URL を**それだけの行**に置く（note は TikTok の URL を単独の行に貼ると埋め込みに変える）。URL の直前の行に「@投稿者（日付、再生数）— 一言」。「削除済み」の動画は URL を貼らず「（現在は削除済み）」と書く
- **コメントの引用**: 「〇〇〇」（N いいね）の形。cid は消す。返信は「→ 返信『〇〇』」
- **段階・界隈の名前**: 下の対応表の日本語に置き換える
- 「観測と推測の区別」のような小見出しは消し、推測は文中で「〜と見ています」「〜だと僕は考えています」の形に溶かす（著者の型）
- 表は note で崩れるので**使わない**（箇条書きに直す）。見出しは `#`〜`###`、太字・引用（`>`）は可
- 重複と内部向けの但し書きを削って読み物として通す（元の7割程度が目安）。**削ってよいのは体裁・重複・注記だけ**で、根拠のある事実は落とさない
